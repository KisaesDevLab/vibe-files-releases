# Security

## Reporting a vulnerability

Please report security problems privately, not in a public issue:

1. Open the [Security tab](https://github.com/KisaesDevLab/vibe-files-releases/security) of
   this repository.
2. Click **Report a vulnerability** and describe the problem, the Vibe Files version, and the
   build identifier shown in the app's footer.

Never include client documents, real client data, passwords or B2 keys in a report.

We aim to reply within five business days and will tell you when a fix is released.

## Supported versions

Only the latest release gets security fixes. Check that you are on it before reporting:
<https://github.com/KisaesDevLab/vibe-files-releases/releases/latest>.

## Checking a download

Every release publishes `SHA256SUMS.txt`. Check the zip against it before running it (see the
README).
