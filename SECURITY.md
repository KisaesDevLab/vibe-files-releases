# Security

Please report security problems by email to **support@kisaes.com**, not as a
public issue. Include the Vibe Files version and the build identifier shown in
the app's footer (for example `vibe-files 0.1.52 (1a2b3c4d5)`), your Windows
version and the steps to reproduce.

Never send client documents, real client data, passwords or B2 keys. If a
sample file is needed to show the problem, make one with made-up data.

We will acknowledge the report and keep you informed until a fix is released.

## Supported versions

Only the latest release gets security fixes. Check that you are on it before
reporting: <https://github.com/KisaesDevLab/vibe-files-releases/releases/latest>.

## Checking a download

Every release publishes `SHA256SUMS.txt`. Check the zip against it before
running it (see the README).
